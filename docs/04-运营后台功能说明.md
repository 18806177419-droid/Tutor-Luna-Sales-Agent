# 运营后台功能说明(产品视角)

版本:v0.4  日期:2026-11-09(与 PRD v0.4 同步)
面向:产品、运营、设计、研发。描述每个页面"给谁用、看什么、能做什么、有什么规则",不涉及实现。
说明:一期按"能用就行"落地,标【一期】的必须做,标【二期】的可后置。口径未确认的内容标【待确认】。

> 变更说明(相对 v0.1):
> 1. 围绕 8 阶段重做:SOP 管理按阶段组织,删除"班期管理"(原写字课概念),改为"体验课"数据视图。
> 2. 新增:阶段看板、内容审核、价格表、受限话题开关、抖音订单回填。
> 3. 首页漏斗、指标改为 Tutor Luna 的转化路径。

## 1. 角色与权限

| 角色 | 能做什么 |
|---|---|
| 运营 | 配置渠道、欢迎语、SOP 步骤、话术、素材;提交内容审核;看数据;处理待办 |
| 法务/合规 | 审核内容(通过/退回/禁用);维护禁止承诺词表 |
| 课程运营 | 维护事实资料、价格表、活动 |
| 销售/客服 | 查看自己名下用户的会话,处理转人工待办,回填订单状态,手动调整阶段 |
| 产品 | 查看全部数据与变更记录 |
| 管理员 | 以上全部 + 账号权限 + 模型/密钥/总开关 |

规则:
- 所有配置类操作留变更记录:谁、何时、改了什么、改前改后。
- **内容必须经"运营提交 → 法务/合规审核 → 通过"才能被 AI 使用或被 SOP 发送**。审核人不能审核自己提交的内容。
- 高风险配置(SOP 启停、价格表发布、受限话题放开)需要二次确认,必要时需要审批【待确认是否需要审批流】。

## 3. 页面说明

### 3.1 首页看板【一期】
**给谁用**:产品、运营每天看。支持按日期、渠道、销售号筛选。
| 区块 | 指标 |
|---|---|
| 进线 | 新增好友、各渠道占比、校验未通过数、欢迎语发送成功率 |
| 转化漏斗 | 进线 → 回复(破冰完成) → 挖需完成 → 开通体验课 → 登录 APP → 首次到课 → 完课 → 抖音下单 |
| 对话 | 用户消息数、AI 独立解决率、转人工率、受限话题命中数、平均响应时长 |
| 主动触达 | 各步骤触达率、响应率、完成率、被每日上限丢弃数 |
| 异常 | 欢迎语失败、标签补偿堆积、通道限额触顶、事件映射失败、待审核内容堆积 |
**规则**:异常区块有红点,点击进入对应处理页。漏斗每一环可下钻到用户列表。

### 3.2 阶段看板【一期,新增】
**给谁用**:销售负责人、运营。
**内容**:8 个阶段为列,展示各阶段当前人数、平均停留时长、本周转入/转出、超时数;沉默池单列。
**能做什么**:点击阶段查看用户列表;批量对用户做"暂停触达/移入沉默池/手动改阶段"(需权限并留痕)。
**规则**:手动改阶段会同步企微阶段标签并写入迁移记录。

### 3.3 渠道规则【一期】
- 增改"渠道参数(state)→ 渠道名 → 渠道标签 → 欢迎语模板"。
- 渠道参数不可重复;有用户使用的渠道只能停用,不能删除。
- 未配置的渠道参数进线时,系统发通用欢迎语并在首页提示补配置。

### 3.4 进线校验规则【一期,新增,规则待确认】
- 可配置校验项:重复进线、已是客户/已成交、黑名单、员工/同行标记。
- 每项设置动作:拒绝进入流程 / 仅通知运营。
- 校验未通过的用户列表可查看原因,并支持"人工放行"。

### 3.5 欢迎语模板【一期】
- 一个模板含多条消息,按序发送;类型:文本、图片、链接卡片、小程序、文件(PDF)、视频。语音不支持。
- 变量:家长称谓、销售名、渠道名;缺失用默认值。
- 保存前必须预览。启用中的模板被修改,新版本只对之后进线的用户生效。
- 现有话术"进线首次打招呼""促建联"可作为首批模板(需经内容审核)。

### 3.6 阶段 SOP 步骤【一期,重做】
**组织方式**:按 8 阶段分栏,每个阶段下是步骤列表,可排序、启停。
**步骤配置项**:
| 配置项 | 说明 |
|---|---|
| 所属阶段、步骤名称 | |
| 触发方式 | 进入阶段后多久 / 体验课到期前多久 / 上一步完成后 / 业务事件(已开通、已登录、首次到课、完课、订单)/ 无回复后追发 |
| 适用人群 | 渠道、年级、英语基础等筛选 |
| 跳过条件 | 如"已登录 APP""已完课" |
| 分支 | 如催下载:未下载 / 已下载未登录,分别用不同话术 |
| 消息内容 | 多条、类型同欢迎语;支持**多个版本轮换**(如催到课 6 条) |
| 追发 | 未响应 X 小时追发,最多 Y 次,追发话术 |
| 完成判定 | 用户回复 / 业务事件 / 回传截图 / 标签变化 |
| 优先级 | 高/中/低,决定每日上限时谁被保留 |
**规则**:
- **只有"审核通过"的内容才能被发送**,草稿或未审核的步骤保存可以,但不会发出,列表显示"待审核"标记。
- 保存时校验:变量有默认值、素材存在且未过期、时间不冲突。
- 动态数据句式(如"X% 同学已完课")必须绑定数据来源;取不到数据时整句不发,后台显示提示。**禁止填写固定数字**。
- 发布前可"模拟":选一个测试用户,查看其完整时间线。
- 已发出的步骤不可删除,只能停用。
- 全局硬规则(只读展示,运营不可改):免打扰时段、每用户每日上限、同时最多 1 个待响应步骤、追发上限。

### 3.7 用户时间线【一期】
- 输入用户后展示:阶段迁移记录、所有 SOP 任务(计划时间、状态、跳过/取消原因、实际内容)、转人工记录、关键事件(开通、登录、到课、完课、订单)。
- 可对单个用户:暂停/恢复触达、手动触发某步骤、标记步骤完成、手动改阶段。

### 3.8 素材库【一期】
- 图片、PDF、视频、链接卡片、小程序卡片(如体验课四节课设置图、4 阶学习闭环图、APP 下载指引、学习报告示例)。
- 字段:名称、类型、标签、有效期、使用次数。平台素材有时效,临近过期标红提示重新上传。被引用中的素材不可删除。

### 3.9 内容库与内容审核【一期,新增】
**内容库**:管理两类 AI 可检索内容。
| 类型 | 说明 | 示例 |
|---|---|---|
| 事实资料 | 一个主题一条 | 体验课规格、设备要求、下载方式、课程结构 |
| 异议策略 | 每个异议一条:家长常见说法 → 应对要点 → 参考话术(短) | 课时短、AI 死板、不纠错、反应慢、听不懂 |
**每条内容的字段**:标题、正文、类型、适用阶段、适用课包、异议类型、**敏感标记**(价格/退款/承诺类)、生效/失效日期、来源与版本、**审核状态**。
**审核状态**:草稿 → 待审核 → 已通过 / 已退回 / 已禁用。
**审核页**:
- 左侧原文,右侧系统提示的**风险标记**(如:疑似写死的统计数据、含承诺性词汇、与已有条目口径冲突、含联系方式)。
- 审核人可填写意见:通过、退回修改、禁用。
- 口径冲突的两条内容不能同时处于"已通过"状态,系统阻止并提示。
**规则**:
- 只有"已通过"且在有效期内的内容会被 AI 检索到;禁用/过期立即下线。
- 《08》文档中已识别的矛盾与高风险条目(升级时间前后不一、模型来源、退款时效承诺、礼品转卖、写死数据、价格构成)默认标为"待确认口径",不进入审核通过。
- 命中测试:输入一个用户问法,查看系统会检索到哪些已审核条目、得分、将如何回答。通过命中测试(运营点击确认)方可发布。

### 3.10 无答案问题【一期】
- 系统回答不出或用户点踩的问题清单,按次数排序。
- 可一键"补充内容"(跳转内容库新建,需走审核)、标记"无需处理"、标记"转人工策略"。
- 产品每周查看一次,是内容库持续改进的主要来源。

### 3.11 价格表与赠品规则【一期建表,放开报价为待确认】
- 字段:课包名称、原价、节数、单价、优惠券、活动说明、实付价、有效期、赠品及兑现规则。
- 由课程运营维护,**发布需审核**;过期自动失效。
- **在"价格/优惠对外口径"确认前,AI 不读取价格表,报价问题全部转人工**(见 3.17 受限话题)。价格表先作为销售和运营的统一参考。
- 校验:实付价与"原价−优惠券−活动"是否一致,不一致时提示核对。

### 3.12 会话回看【一期】
- 按用户、时间、关键词、渠道、阶段、是否转人工、是否命中受限话题查看对话。
- 每条 AI 回复展示:引用的内容条目、识别的意图、所处阶段、耗时。
- 反馈:人工可对 AI 回复"点赞/点踩/填写正确答案",点踩进入"无答案问题"。
- 敏感信息默认脱敏;查看明文需权限并留痕。

### 3.13 转人工待办【一期】
- 内容:待处理用户、转入原因(含"受限话题"类别)、所在阶段、AI 生成的会话摘要(含已采集字段、用户诉求、情绪)、等待时长。
- 操作:领取、标记处理完成、释放回 AI、直接改阶段。
- 超过 X 分钟无人处理提醒负责人;人工接管默认 30 分钟后自动交还(可配置)。
- 关单阶段的议价/退款/报价咨询集中在此处理。

### 3.14 用户档案【一期】
- 展示:阶段、渠道、孩子年级、英语基础、学习目标、家长顾虑、设备类型、体验课进度(开通、登录、到课、完课)、订单状态、是否拒收主动消息。
- 每个字段标注**来源**(信息表/对话/业务后台/人工)与**置信度**;低置信度字段高亮,运营可确认或修正,人工修正优先级最高。

### 3.15 抖音订单回填【一期,订单接口未接入时使用】
- 销售对用户手动标记:已下单/已支付/已退款,可附订单号与金额。
- 标记后触发阶段迁移(已成交/未成交),停止催单。
- 订单接口接入后,此页转为只读对账页【待确认能否接入】。

### 3.16 沉默池【一期】
- 各阶段超时无响应的用户。
- 可配置低频召回策略(间隔、最多次数、话术)和一键批量召回。拒收用户不出现在可召回列表中。

### 3.17 受限话题开关【一期,新增】
**目的**:口径未确认时让 AI 不回答,确认后由运营放开,无需研发发版。
| 话题 | 默认策略 | 状态 |
|---|---|---|
| 价格 | 转人工 | 待确认 |
| 优惠/优惠券/活动 | 转人工 | 待确认 |
| 赠品 | 转人工 | 待确认 |
| 退款政策与时效 | 转人工 | 待确认 |
| 技术来源/模型/升级时间 | 转人工 | 待确认 |
| 体验课"价值 99 元"表述 | 不使用 | 待确认 |
| 产品名称(Tutor Luna / LingoAce Luna Tutor) | 统一用 Tutor Luna | 待确认 |
**可选策略**:转人工 / 固定话术 / 放开(走正常检索)。
**规则**:放开前必须有对应已审核的内容或价格表;修改需二次确认并留痕;放开后观察期内加强抽检。

### 3.18 总开关与日志【一期】
| 开关 | 说明 |
|---|---|
| AI 回复总开关 | 关闭后所有用户消息仅提醒人工 |
| 主动触达总开关 | 关闭后不再发任何 SOP 消息 |
| 单渠道 / 单销售号开关 | 局部止血 |
- 用途:出现事故(话术错误、乱发消息)时第一时间止损,秒级生效。
- 日志:操作日志、发送日志、异常日志,按时间/用户检索。
- 禁止承诺词表:法务维护,AI 输出和 SOP 文案保存时都会校验。

## 4. 关键交互规则(跨页面)

1. 所有"启用/停用/发布/放开"显示影响范围(多少用户/多少任务)。
2. 所有含变量的文案有"预览"和"缺失默认值"。
3. **未审核内容不能发出**,审核状态在每个引用处都可见。
4. 误发风险高的操作,先在测试用户上验证。
5. 列表支持导出(CSV)【二期】。

## 5. 一期不做(明确边界)
- AI 自行报价/议价/承诺退款(默认转人工)
- 系统内收款与支付
- 个性化物料生成
- 语音发送与识别
- 多租户、多语言
- 抖音订单接口自动对接(先手动回填)【待确认】
