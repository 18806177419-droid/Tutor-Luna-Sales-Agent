## 1. 背景与目标

### 1.1 背景
Tutor Luna 通过多渠道获客,用户添加企业微信后,由销售带领完成"领体验课 → 下载登录 APP → 上完体验课 → 购买正式课"的转化。正式课在抖音平台下单。目前全流程依赖销售人工跟进,存在响应不及时、话术不统一、跟进节奏依赖个人、夜间与高峰无法覆盖的问题。

本项目构建接入企业微信的智能客服 Agent,按销售流程的 8 个阶段,承担**自动触达、咨询答疑、需求采集、节点提醒与回访**,在高风险环节(价格、退款、议价、关单)由人工把关。

### 1.2 目标
| 目标 | 指标(初稿,均待用真实数据校准) |
|---|---|
| 新用户秒级触达 | 添加好友到欢迎语送达 ≤ 5 秒,成功率 ≥ 99% |
| 提升体验课到课率 | 加好友→首次登录 APP→首节课到课的转化率较人工基线提升【基线待提供】 |
| 提升完课率 | 到课→完成第 1 节(或 4 节)课的比例较人工基线提升【基线与"完课"定义待确认】 |
| 咨询自动解决 | AI 独立解决率 ≥ 60%(未转人工且用户未重复追问同一问题)【目标值待确认】 |
| 回答可靠 | 幻觉/越权/错误承诺率 ≤ 2%(抽检);**价格、退款类零错误** |
| 响应时效 | 一期不设硬性时延目标,**准确率优先**;先记录各环节耗时形成基线,再决定是否设目标【待确认】。体验兜底:超过一定时间未出结果,先发一句"收到,我帮您确认下"(阈值待定) |

### 1.3 北极星指标(建议)
**体验课完课率**。理由:到课、完课是 AI 能直接影响的环节;下单成交受价格、优惠、销售关单能力影响更大,作为结果指标一并观察,而不是 AI 的唯一考核。【待产品确认】

### 1.4 非目标(本期不做)
- 开放式闲聊、与业务无关的对话
- 系统内收款与支付(成交在抖音完成)
- AI 自行报价、议价、承诺退款(见 §10)
- 面向全体用户的营销群发
- 视频、文件的内容理解(仅兜底)
- 语音的发送;语音接收转文字列为二期【待确认】
- 个性化物料生成(如按孩子姓名生成资料),预留接口
- 后台状态变更→企微标签(**已跑通**,本期仅做标签体系对齐与联调)

## 3. 业务流程(8 阶段)

```
进线校验 → 打标签 → 破冰 → 挖需 → 邀约 → 待到课 → 到课未完课回访 → 完课转化关单
```

| # | 阶段 | 目标 | AI 参与 | 主要数据依赖 |
|---|---|---|---|---|
| 1 | 进线校验 | 判断进线是否合格、是否已有归属 | 无(规则) | 渠道参数、客户库、黑名单【待确认规则】 |
| 2 | 打标签 | 渠道标签 + 初始阶段标签 | 无(规则) | 企微标签接口 |
| 3 | 破冰 | 建立联系,引导用户填写信息表并回复 | 欢迎语无 AI;用户回复后 AI | 信息表数据【待确认字段与位置】 |
| 4 | 挖需 | 采集孩子年级、英语基础、学习目标、家长顾虑 | **高**:AI 按"采集目标"自然追问 | 用户档案 |
| 5 | 邀约 | 让用户确认参加体验课,完成开通与下载 | 高:AI 邀约、答疑、发指引 | 体验课开通状态 |
| 6 | 待到课 | 督促下载登录、上第一节课 | 规则触发提醒为主;用户提问时 AI 答 | APP 登录状态、上课状态 |
| 7 | 到课未完课回访 | 了解卡点,促成补完课 | 中:AI 答疑、识别卡点,必要时转人工 | 到课/完课事件 |
| 8 | 完课转化关单 | 课后反馈、介绍正式课、处理异议、引导抖音下单 | 中低:AI 答疑与异议应对;**报价、议价、关单由人工把关**【待确认,见 §10】 | 完课事件、抖音订单状态【待确认能否接入】 |

阶段规则:
- 用户同一时刻只处于一个主阶段;阶段本身是生命周期标签,与渠道标签、状态标签分组存放。
- 允许跳阶段(如加好友即已开通体验课),不卡流程。
- 阶段迁移触发源:用户行为、业务事件、超时、人工操作(优先级最高)。
- 异常支线:沉默、明确拒绝、转人工、已成交。具体见《07-业务流程与阶段设计》。

## 4. 功能需求

### 模块 A:进线校验、打标签、破冰欢迎(阶段 1–3,不使用 AI)

**A1. 进线校验**【规则待确认】
- 校验项(默认假设):渠道参数是否有效、是否重复进线、是否已是客户/已成交、是否员工或黑名单。
- 校验不通过:不进入 SOP,不发欢迎语;记录原因并通知运营。通过:进入下一步。

**A2. 渠道识别与打标签**
- 通过企微「渠道活码」的 `state` 参数识别渠道,配置表:`state` ↔ 渠道名 ↔ 渠道标签。
- 无法识别时打"渠道未知"标签,发通用欢迎语,告警运营。
- 同时打初始阶段标签"破冰"。
- 标签失败重试 3 次(指数退避),仍失败进补偿队列与告警。
- 沿用模块 C 的标签通道,渠道类标签与阶段类、状态类标签分组管理,互不覆盖。

**A3. 破冰欢迎语**
- 按渠道匹配欢迎语模板;支持文本、图片、链接、小程序、多条按序发送;支持变量(家长称谓、销售名)。
- 内容含"引导填写信息表"等固定动作(现有话术:"进线首次打招呼""促建联")。
- 无 AI,纯配置;须在平台有效期内完成发送(企微欢迎语凭证时效很短)。
- 用户长时间未回复:按追发规则发 1–2 次破冰追发(话术待销售提供)。

**A4. 边界**
- 删除后重新添加:视为重新进线,渠道标签追加;阶段标签按最新状态【待确认:重置还是延续】。
- 重复回调幂等,同一事件只发一次。

**A5. 验收**
- 各测试渠道扫码添加,标签与欢迎语正确无重复;重放同一回调 10 次仅发 1 次;校验不通过的用户不收到欢迎语。

### 模块 B:阶段感知的智能答复(阶段 3–8)

**B1. 消息接入**
- 支持文本、图片、语音(二期)、其他。连续多条消息按时间窗(默认 3 秒)合并处理。

**B2. 多模态**
| 类型 | 处理 |
|---|---|
| 文本 | 直接进入意图门控 |
| 图片 | 转存 → 多模态识别:分类 + 描述 + OCR。**本业务重点场景**:APP 登录/课程页截图、孩子上课截图、报错截图、支付/订单截图(抖音)。无关或看不清时追问 |
| 语音 | 二期(ASR 转文字) |
| 视频/文件/其他 | 兜底话术,必要时转人工 |

**B3. 意图门控**
- 分类:`业务咨询` / `异议` / `闲聊无关` / `敏感需转人工` / `无意义` / `拒收主动消息`。
- 「不闲聊」定义:不脱离业务目标的闲聊。围绕体验课与正式课的共情、鼓励、异议应对属业务话术,允许;无关话题固定话术拉回,不调用生成。
- `敏感需转人工`:退款办理、投诉、威胁、法律、强烈负面情绪、明确要人工,以及 §10 中【待确认】口径的问题(价格、优惠、赠品、退款政策细节、模型/技术来源、升级时间)。
- `拒收主动消息`:用户说"别发了/不需要",立即暂停该用户主动触达。
- 连续 N 轮闲聊(默认 2)后降频,防刷。

- **意图词表**:意图分三层(路由意图 / 主题或异议类型 / 实体),第二层取值与内容库的"主题/异议类型"标签使用**同一套受控词表**,由**产品负责维护**,销售和运营评审。意图识别结果以"检索指令单"形式驱动检索(路由、过滤、改写、加权),详见《09》。

**B4. 阶段感知**
- 每次回复前读取:当前阶段、渠道标签、用户档案、最近对话(默认 6 轮)。
- 检索按阶段过滤内容:破冰/挖需阶段不检索报价、关单类内容。
- 回复末尾可带"推进动作":当前阶段有未采集字段或下一步动作时,自然引导(而非生硬追问)。

**B5. 阶段 4:挖需(采集)**
- 每个阶段定义"采集目标字段"。挖需阶段默认:孩子年龄/年级、英语基础、学习目标、家长顾虑/关注点【必采字段待销售确认】。
- 已在信息表中采集的字段不重复提问【信息表字段待确认】。
- 采集到的字段写入用户档案,标注来源(对话/信息表/人工)与置信度;低置信度先向用户确认。
- **现有销售话术缺少挖需提问话术,须由销售补充**;补充前,AI 仅可使用运营审核通过的提问模板,不自由发挥。

**B6. 阶段 5–8:邀约、回访、异议应对**
- 邀约:根据挖需结果介绍体验课价值,发开通与下载指引(设备要求、下载方式、登录方式见话术事实资料)。
- 到课未完课:先询问卡点并分流(听不懂/没时间/设备问题/孩子不愿意),按卡点给出应对;无法解决转人工。
- 异议应对:对销售话术中的 12 类异议(课时短、AI 死板、不纠错、反应慢、听不懂、对比真人、无测评、语法教学、无作业无教材、不可重复学、全英教学、礼品折现等),AI 以"应对要点"为依据,结合用户原话**改写**后回复,不照搬长话术。
- 价格、优惠、赠品、退款:见 §10。

**B7. 转人工**
- 触发:敏感意图、用户要求、检索无结果连续 2 次、置信度低、用户不满、进入关单阶段的议价/退款。
- 动作:通知所属销售(方式待确认),给用户过渡话术,AI 对该会话静默(默认 30 分钟后恢复,可手动释放),附会话摘要。

**B8. 安全与合规**
- PII 脱敏;提示词注入防护;输出审核(禁止承诺词表:"保证效果/提分""一定退款""当天到账"等,由运营法务维护)。
- **AI 身份披露**:AI 回复是否明示为 AI【待确认,见 §10】。
- 全量会话留痕,保留期待确认(默认 180 天)。

**B9. 验收**
- 业务问答 ≥ 90% 准确;价格/退款类 0 错误;闲聊拒答 ≥ 98%;敏感转人工召回 ≥ 95%;图片分类 ≥ 90%;阶段过滤正确率 100%(不得在破冰阶段出现报价)。

### 模块 C:状态与阶段标签同步(已跑通)

- 保持现有能力。本期工作:
  1. 标签分组:渠道类(模块 A)、阶段类(本模块新增)、状态类(现有);各管各的。
  2. **阶段迁移 = 状态变更**,复用现有同步通道:旧阶段标签移除、新阶段标签添加,并记录迁移日志(时间、来源、原因)。
  3. 模块 B 读取标签与阶段做个性化与检索过滤。
  4. 联调回归。
- 已跑通的接入方式未知【待确认】,影响能否复用其通道与事件源。

### 模块 E:阶段化主动触达引擎(阶段 3、5–8)

**E1. 步骤定义**(全部可配置)
| 要素 | 说明 |
|---|---|
| 所属阶段 | 8 阶段之一 |
| 触发时机 | 相对时间(加好友后 N 分钟/小时)、距体验课过期倒计时(体验课有效期 4 天)、业务事件(已开通/已登录/首次到课/完课/订单状态)、上一步完成后 |
| 适用人群 | 按渠道、阶段、档案字段(如年级)筛选 |
| 跳过条件 | 如"已登录 APP""已完成第一节课" |
| 消息内容 | 文本、图片、链接卡片、小程序、文件、视频;可多条 |
| 变量 | 家长称谓、孩子称呼、销售名、体验课剩余天数;缺失有默认值 |
| 追发 | 未响应 X 小时追发,最多 Y 次 |
| 完成判定 | 用户回复 / 业务事件(如登录、到课) / 回传截图 / 标签变化 |
| 优先级 | 受每日上限约束时决定保留谁 |

**E2. 现有话术可映射的步骤**
| 阶段 | 可配置的步骤 |
|---|---|
| 破冰 | 首次打招呼、促建联(两条) |
| 邀约 | 确定体验课时间、软件下载方式 |
| 待到课 | 催下载(两条,按"已下载未登录"分支)、催到课(6 条轮换,含赠品钩子) |
| 到课未完课 | 回访 1 条(需补充多次回访与卡点分流) |
| 转化 | 课后反馈(含学习报告数据) |

**E3. 调度与硬规则**
- 免打扰时段(默认 21:30–08:00)内顺延;每用户每日主动消息上限(默认 5 条);同一用户同时最多 1 个待响应步骤;追发上限。以上为系统级硬规则,运营不可绕过。
- 用户回复时先走模块 B,再决定是否推进 SOP。
- 用户拒收/转人工接管/已成交:暂停主动触达。
- 事件超限时:高优先级顺延,低优先级丢弃。
- **催到课等话术中的动态数据**(如"X% 同学已完课""开口次数 N 次")必须来自真实数据,取不到则不发该句,不得写死。

**E4. 通道限制**(可行性风险)
- 企微对自动主动发消息存在限制(据社区资料转述:群发每月对同一客户最多 4 条;微信客服回复窗口 48 小时/5 条;均待官方文档核实)。通道未确认前,模块 E 只能完成调度与配置。
- 备选:第三方 SCRM 能力,或"AI 生成+销售一键发送"的半自动方式。详见技术方案 §3.3。

**E5. 验收**
- 配置示例 SOP 后,各步骤按预期发出(误差 ≤ 1 分钟);已登录用户不收到催下载;免打扰时段不发送;用户提问时先答问题不插播;日上限生效。

### 模块 F:知识库与话术管理(新增)

**F1. 内容分四类,去向不同**
| 类型 | 内容 | 去向 |
|---|---|---|
| A 事实资料 | 体验课规格(4 节、每节 15–20 分钟、4 天有效期)、设备要求、下载方式、教材来源、课程结构、正式课规格 | 知识库(RAG),AI 回答依据 |
| B 异议策略 | 12 类异议的应对要点 | 知识库(RAG),按异议类型检索,AI 改写后使用 |
| C 主动触达话术 | 催下载、催到课、回访、课后反馈 | 模块 E 步骤配置,不进 RAG |
| D 价格优惠 | 课包价格、优惠券、活动、赠品 | **结构化价格表**,AI 只读,不进 RAG |

**F2. 内容准入**
- 入库前必须经运营+法务审核,标记"已审核"方可被检索;未审核内容不可用。
- 《08》中已识别的矛盾与风险条目(升级时间前后不一、模型来源表述、退款时效承诺、礼品转卖、写死的统计数据、价格构成不清、品牌名称不统一)在口径确认前**不入库**。
- 每条内容带元数据:类型、阶段、异议类型、适用课包、生效/失效日期、来源版本、合规状态、敏感标记。

**F3. 话术缺口**(须销售补充)
挖需提问话术;未到课异常(设备不支持、登录失败、麦克风权限);到课未完课的多次回访与卡点分流;抖音下单指引与下单后确认;未成交的长期跟进;退款办理流程话术。

**F4. 价格表**
- 由运营维护,字段:课包、原价、节数、单价、优惠券、活动、实付价、有效期、赠品及兑现规则。
- AI 报价只能读取价格表原值,不得计算或推断;价格表缺失或过期则转人工。【是否允许 AI 报价待确认,见 §10】

## 9. 灰度与回退

内测 → 单渠道小流量 → 扩大 → 全量。回退条件:误发/错发/错误承诺任一例;删除好友率显著上升;平台限制通道;抽检准确率 < 80%。回退方式:总开关关闭 AI,全部转人工。
